# EVIDA — 근거에서 다음 연구 행동으로

**[EVIDA 실행](https://evida.ndagentevida.com)** · **[사용 방법과 예시 질문](docs/DEMO_HOW_TO_RUN.md)** · **[성능 지표와 평가 기준](evaluation/README.md)**

EVIDA는 **질환과 연구 목표에서 출발해, 근거와 관측을 다음 연구 판단으로 연결하는 신약개발 연구 플랫폼**입니다. 기전과 개입 방향을 비교하고 후보를 찾은 뒤, 무엇을 무엇과 비교하고 어떤 값을 읽을지 구체적인 다음 실험으로 연결합니다. 연구자가 새 결과나 조건을 추가하면 앞선 판단과 변경 이유를 함께 보존합니다.

## 저장된 세 연구로 확인하기

| 연구 | 확인할 흐름 | 바로 열기 |
|---|---|---|
| IPF | 질환 목표 → 검토 기전 → 연결 후보 → 다음 비교 | [IPF 연구](https://evida.ndagentevida.com/?workspace=ws_3c8fe9df9cd14339) |
| PDE4B | 출발 화합물과 생성 구조 → PDE4B/PDE4D 기능 비교 설계 | [PDE4B 연구](https://evida.ndagentevida.com/?workspace=ws_1ff05aa2d7c24e0e) |
| ALS | 이전 판단 → 공개 결과와 검토 피드백 → 조건을 구분한 후속 판단 | [ALS 연구](https://evida.ndagentevida.com/?workspace=ws_4475545a286541b2) |

화면의 **한눈에 보기 · 기전 · 후보 · 실험 · 근거 · 원자료**를 따라 확인할 수 있습니다. 기전 상세의 **이 기전 검토하기**에서 탐색 방향을 선택하고, 이유를 입력한 뒤 실제 검토를 시작합니다. 저장된 판단에 대한 설명 질문과 새로운 관측·조건 입력을 구분해 제공합니다.

현재 공개 서비스는 **Claude Opus 5 · high / 개발자 구독 연결**을 사용합니다. 대회 API는 할당량 소진 상태이며, 심사와 지속 사용에는 대회 API 재충전을 권장합니다. 실제 연결 상태는 화면의 모델 안내에 표시됩니다. [읽기 전용 미리보기](https://evida.ndagentevida.com/preview/)에서는 보존 사례를 살펴볼 수 있습니다.

## 구성과 실행 환경

이 저장소는 최종 공개 제품의 **검토 가능한 소스와 평가 자료**를 제공합니다. 실제 동작 확인은 위 데모와 예시 질문으로 시작합니다.

| 경로 | 내용 |
|---|---|
| `evida/` | 연구 기록, 도구 실행, 출처·참조 검사, 과학 계산, HTTP 서비스 |
| `web/` | 실제 화면 소스·번들, 구조 뷰어·폰트와 라이선스 |
| `configs/` | 연구 지시, 공개 예시, 과학 패키지 목록과 배포 자원 템플릿 |
| `runtime/` | Claude 구독 연결과 응답 형식 검증 소스 |
| `evaluation/` | 연구 흐름 16회 비교·공개 검색/활성 예측 평가·저장 출력과 재검산 코드 |
| `docs/` | 사용 방법, 구조, 방법 채택 범위 |

과학 계산 환경은 **Python 3.12, RDKit 등 고정 패키지**와 도구별 공개 자원·모델을 사용합니다. `configs/science-packages.lock.txt`와 자원 템플릿에서 버전·연결 조건을 확인할 수 있습니다. 구독 실행에는 검수된 LROS 기반 adapter, Claude CLI, 운영자의 인증과 검토 프로필이 필요합니다. 상세 의존성은 [런타임 안내](runtime/README.md)에 정리했습니다. 운영 DB·사용자 입력·모델 원응답·인증·가중치는 운영 환경에서 별도로 관리합니다.

## 같은 조건에서 비교한 연구 흐름

질문4개 × 반복2회의 **각8시작**을 같은 GPT-6 Sol/medium, 도구와 응답 예산으로 비교했습니다.

| 평가 기준 | 직접 절차 | EVIDA 절차 |
|---|---:|---:|
| 최종 판단 게시 | 7/8 | 8/8 |
| 다음 행동의 여섯 요소 충족 | 6/8 | 7/8 |
| 기전·후보·근거·다음 행동의 네 연결 | 1/8 | 4/8 |
| 새 측정 카드의 여섯 요소와 가설 연결 | 3/8 | 3/8 |

원 시작 수와 실패를 포함한 분모를 유지했습니다. 이는 동결된 개발 평가이며, 현재 Claude 연결과 후보의 실제 생물학적 효능은 각각 별도 확인 대상입니다. [평가 정의·원 행·집계](evaluation/README.md)에서 각 결과의 조건을 확인할 수 있습니다.

## 공개 데이터로 확장한 부품 평가

| 부품·비교 대상 | 평가 규모 | 결과 |
|---|---|---|
| MedCPT 의미 검색 / 고정 BM25 | NFCorpus 공식 질문 323개·문헌 3,633개 | nDCG@10 **0.3072 → 0.3655**, Recall@100 **23.72% → 34.94%** |
| 현재 RF 활성 예측 / 학습 평균 기준 | MoleculeACE 30과제·29표적 ID·평가 기록 9,802건 | 과제 평균 MAE **1.0106 → 0.5553**, 평균 Spearman **0.7582** |

같은 자료와 사전에 고정한 조건에서 평가했습니다. 검색은 관련 문헌을 찾는 능력, 활성 모델은 공개 활성값의 예측 오차를 측정합니다. 공식 분할·전체 과제·신뢰구간과 원 순위/예측을 보존했고, [확대 평가의 조건·전체 결과·재검산 코드](evaluation/components-20261002/README.md)를 공개합니다.

[CReM 생성 평가](evaluation/crem-generation-20261002/README.md)는 공개10과제의 실행 상태와
완료5과제의 실제 반환300건을 제공합니다. 반환 구조300/300의 유효성과 출발 화합물·변환
연결을 검수했으며 원구조·공식 출처·재계산 코드를 함께 보존했습니다.

현재 Claude Opus5/high 경로의 [추가 질환 평가](evaluation/claude-expansion-20261002/README.md)는
원8연구 단위에서 최종 완료0건으로 종료했습니다. 형식 수리와 입력 크기 제한, 모든 시도·실패·
사용량을 별도 기록했고 기존 GPT16 및 부품 평가의 분모와 구분했습니다.
