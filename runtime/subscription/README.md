# Subscription transport reference

The bridge delivers the product request, tool contracts, retained source views and coordinator observations to the selected subscription CLI. The product validates each returned action before dispatch. Model identity, source hashes and failure records remain inspectable.

The GPT route preserves the selected model during transient provider-capacity recovery. Input-size observations remain recorded alongside exact input-restoration checks. Host-owned authorization selects the enabled routes and credentials remain outside this package.

The deployed host supplies the reviewed science runtime and shared launcher dependencies. These files document that host integration; they do not include account authentication or workspace data.
