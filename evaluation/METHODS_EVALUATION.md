# 방법 비교의 근거 — 문헌 검색과 활성 입력 처리

완료한 개발 비교의 집계와 적용 조건을 제공합니다. 원 수치는 [methods-summary.json](methods-summary.json)에 보존했습니다. 이 내보내기에서는 보존 예측·평가 행의 산술만 대조했으며 학습·검색 추론·bootstrap·외부 모델 호출을 다시 실행하지 않았습니다.

## E2. 보존 문헌의 의미 검색

- SciFact 5,183개 문헌과 동일 질문을 사용해 BM25와 공개 MedCPT bi-encoder를 비교했습니다.
- 300개 질문을 검색했고, 아래 주 지표는 정답 근거가 있는 **188질문·209문헌 근거 쌍**을 대상으로 합니다.
- 지표는 질문별 상위 10개 문헌의 정답 회수율 평균입니다. 각 질문의 정답 문헌 수를 분모로 계산한 뒤 188개 질문을 평균합니다.
- 검색 추론에 정답을 전달하지 않았고, 이 비교에서 매개변수·임계값을 조정하지 않았습니다.

| 지표 | BM25 | MedCPT | 차이 |
|---|---:|---:|---:|
| 평균 recall@10 | 92.42% | 97.22% | +4.796%p |

차이의 보존 95% 구간은 **+1.975~+8.286%p**입니다. 출처가 연결된 고정 46묶음을 단위로 두 방법을 함께 재표집한 paired percentile bootstrap 2,000회(seed 20261002) 결과입니다. 개별 질문을 독립 표본으로 계산한 구간과 구분합니다.

**제품 적용:** 이미 확보한 제목·초록에서 읽을 문헌을 찾는 선택 기능으로 연결했습니다. 정확한 원자료 이동, 내용 해시 기준 증분 색인, 기존 자료 목록을 함께 제공합니다. 검색 관련성 순위는 근거의 강도·답변 정확도·치료 효과와 각각 구분합니다.

**평가 범위:** 공개 개발 자료의 검색 부품 비교입니다. 저자 모델 학습 자료와의 노출 가능성이 있고, 저자 전체 시스템의 재현이나 모든 질환에서의 우위를 뜻하지 않습니다.

## E4. 원 측정 의미를 보존하는 활성 입력

- nM 원값은 `pActivity = 9 − log10(value_nM)`으로 변환하고 관계기호를 보존합니다. `IC50 <100 nM`은 `pIC50 >7`이라는 경계로 남습니다.
- 적합 전에 정확한 구조 수가 가장 많은 측정 종류 하나를 선택하고 정확한 값만 점 회귀에 사용합니다. 경계값과 다른 측정 종류의 원행은 함께 보존합니다.
- 기존 Murcko 골격 분할을 두 적합 전에 고정하고, 두 처리 방식에 **동일 화합물의 동일한 정확 IC50 평가값**을 적용했습니다.
- 입체 정보를 포함한 Morgan fingerprint(radius 2, 2,048bit)와 같은 Random Forest 설정(나무 300개, 최소 leaf 2개, seed 20260930)을 사용했습니다.

| 자료 | 평가 화합물 / 골격 | 학습 수 전 → 후 | Spearman 전 → 후 | MAE 전 → 후 |
|---|---:|---:|---:|---:|
| LPAR1 | 208 / 168 | 958 → 571 | 0.580 → 0.606 | 0.508 → 0.479 |
| PDE4B | 955 / 955 | 3,563 → 2,656 | 0.743 → 0.771 | 0.752 → 0.714 |

MAE의 단위는 pIC50입니다. JSON에는 반올림 전 수치와 학습 평균 예측의 MAE도 포함했습니다. LPAR1의 보고 1,553건과 PDE4B의 6,186건을 보존했고, 경계값 기록은 각각 107건과 1,035건입니다. PDE4B 경계값에는 반환 중복 26건이 포함됩니다.

**제품 적용:** 원 측정 의미를 보존하는 입력 처리를 운영 경로에 채택했습니다. 두 개발 사례의 개선 방향은 그 변경을 점검한 결과입니다. 과거 혼합 측정 예측은 당시 기록으로 유지하고 새 조건부 예측과 구분합니다.

**평가 범위:** 전후 학습 집합 크기가 달라지는 처리 방식 비교이며, 각 수리 항목의 효과를 분리한 시험은 아닙니다. 같은 IC50도 실험법·종·노출 조건의 동등성은 원 조건에서 확인합니다. 이 개발 자료는 새로운 독립 검증 집합이 아니며, 해당 수치에 대한 신뢰구간·통계적 유의성이나 후보의 실측 효능을 주장하지 않습니다.

## 출처와 수치의 귀속

- **MedCPT 원논문:** Jin Q, et al. *MedCPT: Contrastive Pre-trained Transformers with large-scale PubMed search logs for zero-shot biomedical information retrieval*. Bioinformatics. 2023;39(11):btad651. [원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC10627406/).
- **SciFact 저자 자료:** [Allen Institute for AI의 공개 데이터·구현](https://github.com/allenai/scifact).
- **활성 원자료원:** [ChEMBL](https://www.ebi.ac.uk/chembl/)과 [BindingDB](https://www.bindingdb.org/). 해당 자료에서 보존한 원 측정의 종류·관계·조건을 대조했습니다.

위 논문·자료원은 방법과 데이터의 출처입니다. 이 문서의 성능 수치는 EVIDA에서 완료한 비교의 결과이며 저자 논문의 보고값으로 귀속하지 않습니다. JSON의 SHA-256은 원 집계·프로토콜·예측 파일을 식별합니다. 공개 내보내기는 집계·조건·해시만 포함합니다.
