## Question and scope

On the same frozen 30 KnockTF contrasts, does current pinned R decoupleR ULM or MLM recover the annotated perturbed TF better than raw signed WMEAN or the TF's own logFC, within each of two fixed priors? Primary results use the **published stored representation with zeros retained**. A separate sensitivity omits each row's exact numeric zeros according to the author's optional zero-omission convention. This is a short numerical component diagnostic, not native t/z-input efficacy, experimental TF-activity truth, original-paper metric reproduction, or a disease-specific target validation.

The panel was selected before expression acquisition: seed 20261011, original metadata order shuffled once, first 30 distinct TF and Profile.ID, no expression/coverage/success filter. The 907-task/456-TF/646-profile inventory and historical own-TF-logFC<−1 subset (388 tasks/234 TF/310 profiles) are preserved separately. No refiltering to the historical 388 subset, replacement of a failed task, or panel expansion is permitted. Metadata and prior resources are historically known, so this is exploratory replay rather than unseen validation. Direction is the published inhibitory-corpus assumption; ambiguous CRISPR/edit metadata remains flagged, not silently reinterpreted after scores.

## Methods, priors and batching

Pin R 4.4.3 / decoupleR 2.12.0 and all interpreter/package/network hashes from the product's current `regulon-resources.json`; verify them before launch and scoring. DoRothEA and CollecTRI are distinct fixed priors, not independent biological replications. No resource refresh, gene-symbol aliasing, TF dropping to resolve collinearity, package install, regularization or fallback is allowed.

For each representation × prior:

- ULM: `decoupleR::run_ulm(mat, net, minsize=5L, center=FALSE, sparse=FALSE, na.rm=FALSE)`.
- MLM: `decoupleR::run_mlm(mat, net, minsize=5L, center=FALSE, sparse=FALSE, na.rm=FALSE)`. Keep all structurally eligible TF covariates. Installed `.mlm_analysis` explicitly errors on aliased/collinear sources; preserve that failure, do not remove predictors and rerun.
- Raw WMEAN: `decoupleR::run_wmean(mat, net, minsize=5L, times=2L, seed=0L, sparse=FALSE, randomize_type='rows')`; select only `statistic == 'wmean'`. The wrapper requires at least two randomizations although its raw weighted mean does not depend on them. Preserve raw wrapper output if produced, but exclude its p-values, normalized/corrected scores and two-draw permutation quantities from evaluation. The raw formula is sum(weight × supplied gene value) / sum(abs(weight)) over present targets; weight is mor × the author's default likelihood (1 for these TSVs). Do not interpret this as a variance-adjusted significance score.

For each representation, compute one TF-own-logFC vector over the union of source TF names in the two prior TSVs, from the same input values only. Reuse it across prior-specific scoring universes; that reuse is not another experiment. A gene present with 0 has a **valid neutral score in stored_zero**. In omit_zero it is **unavailable_zero_omitted**, not 0, a bottom rank or failed inhibition. An absent gene is **unavailable_gene_absent** in either condition. All selected perturbed TF genes are present in the original matrix; this fact does not alter the panel or supersede the per-condition availability rules.

Primary matrices have identical support, so batch all T01–T30 columns once per method/prior arm. Sensitivity runs each T01–T30 separately in fixed order because its gene supports differ. This batching is predeclared, not selected by speed or outcome. The common per-arm deadline includes all its row calls. WMEAN uses the same fixed seed on every call; only raw scores are retained for metrics.

## Fixed TF universes and availability

Compute eligibility using packets and priors only, before labels or scores. For task t, representation r and prior n, let E(t,r,n) be all prior TFs with at least 5 distinct target genes present in that representation. Each numerical method receives the full prior and must estimate every E member; it may use different regressors internally only as specified by its pinned author function. The comparison driver must not narrow MLM's model to the target label or a scoring intersection.

For within-prior ULM–MLM and ULM–WMEAN comparisons, the scoring universe is E. For ULM–own-expression, it is E intersected with all TFs having an available own-gene value in that representation. This removes unavailable **candidate TFs using input-only rules**, not the known perturbed label. If the annotated target is outside the universe, record target-unavailable for that comparison in the full-30 table; do not impute a score. If the universe has fewer than two TFs, normalized-rank comparison is unavailable and its reason is recorded.

A comparison row requires both methods to return unique, finite scores for the **entire precomputed universe**. Do not silently shrink a universe to finite outputs. Unexpected missing/duplicate/nonfinite required TF scores make that task's comparison invalid; retain partial outputs and classify the failure. An error affecting a whole primary batch produces terminal failures for all its 30 rows. The other independent arms still run unless source/input integrity fails.

Prespecified cross-prior sensitivity for each numerical method uses E(dorothea) ∩ E(collectri) per task/representation, never a union with missing scores filled as zero. Prespecified cross-representation sensitivity uses the relevant primary/sensitivity universe intersection for each fixed method/prior or pair. Report original E sizes, intersection size, eligible target counts, technical success and pair-valid counts. Coverage gains cannot be claimed as paired accuracy gains. Keep all 30 rows even when a comparison has zero valid pairs.

## Scoring, separate from acquisition and inference

Workers receive opaque IDs and gene values only, plus frozen method/resource configuration. They never read metadata or target labels. Known labels have been inspected historically; no claim of analyst blinding is made. Nevertheless, the scoring program must not open or join labels until the complete planned output/receipt manifest is sealed and validated.

All numeric methods are ranked by ascending score under the fixed inhibitory-direction assumption. Exact numeric ties use midranks with no arbitrary noise or epsilon. Per-task outputs: target rank, reciprocal rank, normalized rank (rank−1)/(universe_size−1), and top-1/top-5 fractional capture. For a tie group of m candidates with a strictly lower-scored candidates, capture at k is min(1, max(0, (k−a)/m)). These are recovery diagnostics, not proof other TFs were biologically unperturbed. Store the complete evaluated candidate universe and ranks.

Primary summaries: paired macro-average normalized-rank and reciprocal-rank differences for ULM versus each comparator within each prior, plus full availability counts. Secondary top-k capture and cross-prior comparisons retain labels as secondary. Report per-task paired differences; no significance-based winner/adoption claim, favorable post-hoc metric selection, or mixing of primary and zero-omission scores. Historical own-expression-loss subset counts may be descriptive only; do not reselect the panel or make that subset the primary result. Denominators are always explicit: 30 planned; input eligible; method usable; paired valid. Failed/unavailable values remain null, never rank 0 or a numerical worst-score imputation.

## Implementation clarifications before final freeze

Reciprocal rank is exactly **1 / midrank**. Every paired difference is comparator b minus reference a: a positive normalized-rank difference favors a, while a negative reciprocal-rank/top-k difference favors a. The own-expression zero omission state is unavailable, not a sign-based failure. Raw WMEAN alone must be finite; nonfinite two-draw normalized/corrected quantities can remain in the preserved raw artifact without invalidating finite raw scores.

The scorer validates all 420 records and actual successful raw-call identities before its label loader can run. Deferred label-bearing files (selection-labels, original metadata, full shuffled metadata order) are byte-hashed and checked only after this label-free gate, before JSON parsing/join; their expected hashes were pinned in the preparation. Worker/scorer numerical paths never use the label metadata to choose a model, prior, support or universe. The label-free source/input and execution pins are verified before and during inference; a changed execution pin is a stop condition.

The final worker reports its loaded decoupleR package path and R home so the gate can compare them with the pinned runtime. These metadata fields were added after the six synthetic author calls; their exact preflight source snapshot is retained, and the only R-worker change is recorded in `synthetic-metadata-amendment.json`. No numerical method body, arguments or synthetic result was changed. The Python timeout accounting was tightened to include request serialization and startup before waiting on the child. Real worker affinity is restricted to two available CPUs as well as setting math-thread environment limits.

`run_trial.py` additionally requires a coordinator-supplied receipt with execute_actual_panel=true, independent_review_passed=true, and matching protocol/execution-freeze SHA256. No such approving receipt is supplied by this preparation. `approval-template.json` is false by default. Execution freeze records immutable code; it is not permission to start the original 30 tasks.
