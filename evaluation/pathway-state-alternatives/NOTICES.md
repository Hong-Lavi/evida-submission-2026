# Software and input provenance

The arithmetic and replay utilities in this package are EVIDA-authored experiment code. The portable arithmetic evaluator was adapted from the separately written independent-review utility, not from the product validator. Its changes are recorded in `code-provenance.json`. No author solver code, compiled runtime, model weights, biological prior database or sample-level data are bundled. No blanket license grant is asserted for third-party inputs.

- CARNIVAL 2.16.0: installed package DESCRIPTION declares GPL-3; Bioconductor RELEASE_3_20, commit a7305b3. Credit the CARNIVAL authors and the cited method. This software declaration does not establish a license for every input network resource or confer biological validity on its output.
- CBC 2.10.13, conda build h4d16d09_1: installed conda metadata declares EPL-2.0, while the retained installed LICENSE file begins “Eclipse Public License - v 1.0”. Both observations are recorded without silently choosing between them. The binary and third-party source are not distributed here.
- OmniPath acquisition: the retained request used `license=academic`, with sources/references fields. Its acquisition receipt explicitly limited the trial to academic development and did not infer redistribution/commercial-use permission. Removing edges supported only by SIGNOR was a scientific prior sensitivity rule, not license clearance. The retained 3,520 edges still carry 99 source-support labels, including multi-source overlaps.
- The real LP is a mathematical encoding of that retained prior; its variable map links all encoded edges to biological names. Removing URLs or changing it to JSON would not establish new permission to redistribute the underlying database. Real LP/map/full-prior and named result-edge lists are therefore absent from this candidate. Their hashes and the exact missing-input scope remain explicit.
- The released numerical result vectors, aggregate metrics, two TF fits, fixed query definitions and independent verification summaries are generated analysis outputs. Logs retain the complete optimization trace with only absolute command-line paths replaced; original and public hashes are in `log-transformations.json`. They are not described as byte-identical originals.
- The synthetic control is a small EVIDA-authored mathematical example, clearly separate from the real scientific input. It was not fitted by CBC and is not an additional empirical result.

This package was assembled from local retained evidence. No fresh resource-licensing page was fetched, and no unresolved resource terms are described as verified. A release containing the full named graphs or LP/map requires that additional source-level check first.
