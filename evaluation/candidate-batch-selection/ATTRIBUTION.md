## Models and methods

Tanimoto GP: Austin Tripp, Sergio Bacallado, Sukriti Singh, José Miguel Hernández-Lobato, *Tanimoto Random Features for Scalable Molecular Machine Learning*, NeurIPS2023. [Paper](https://arxiv.org/abs/2306.14809), [author commitf0edc6b88471ccc9eb19c05ed3e16a6dbf7879e2](https://github.com/AustinT/tanimoto-random-features-neurips23/tree/f0edc6b88471ccc9eb19c05ed3e16a6dbf7879e2). The fitted estimator used the exact `TanimotoKernelGP`/`T_DP` author model with native binary Morgan features; it did not use the random-feature approximation. The MIT author notice is retained. This package includes saved model parameters, original predictions, and recovered joint posteriors; it does not redistribute the author implementation or repeat fitting. The adjacent conditional-activity-models component package documents that fit.

qPO: Jenna Fromer, Runzhong Wang, Mrunali Manjrekar, Austin Tripp, José Miguel Hernández-Lobato, Connor W.Coley, *Batched Bayesian optimization by maximizing the probability of including the optimum*. [arXiv2410.06333v2](https://arxiv.org/abs/2410.06333v2), [DOI10.1021/acs.jcim.5c00214](https://doi.org/10.1021/acs.jcim.5c00214). The independent implementation uses sampled winner-set coverage: for a batch, count draws whose maximizer set intersects it. Unique winners give additive optimization; nonunique winners use the declared S1 greedy uncovered-event approximation. pTop10 instead averages fractional top-ten memberships and selects the largest additive scores. These are different objectives.

The inspected [qPO author repository](https://github.com/jenna-fromer/qPO/tree/ba4f72a4439634a2ff4909cf00205d2260c94750) is pinned at commit`ba4f72a4439634a2ff4909cf00205d2260c94750`. No redistribution license was established. Its source file and probe harness are **not included**, even where original protocol hash lists reference them. Only bibliographic locators, hashes, and the original four-candidate synthetic probe receipt are retained. That probe used one unchanged author function with a fixture model, not a full author GP or comparative scientific validation. No paper text or unlicensed author-code excerpt is bundled.

## Public export

`export_package.py` is an allowlisted transform. It excludes the unlicensed files, copies NPZ/CSV scientific bytes exactly, preserves all numerical experiment records, and replaces only private filesystem locators/operational session identifiers. `source-map.json` records each original logical locator, original SHA256, public SHA256, and operation. All40 exported Python source files are byte-identical to their originals, and all function/class ASTs match; `source-parity.json` records that check. Public package verification cannot retrieve omitted original private files from their hashes. It verifies the included exact scientific inputs and records; portable replay creates a new explicit integrity graph for these supplied files.
