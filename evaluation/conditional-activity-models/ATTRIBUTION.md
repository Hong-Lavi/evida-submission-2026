# Sources and licenses

**Tanimoto GP.** Austin Tripp, Sergio Bacallado, Sukriti Singh, and José Miguel Hernández-Lobato. *Tanimoto Random Features for Scalable Molecular Machine Learning*. NeurIPS 2023. [Paper](https://arxiv.org/abs/2306.14809), [author code](https://github.com/AustinT/tanimoto-random-features-neurips23/tree/f0edc6b88471ccc9eb19c05ed3e16a6dbf7879e2).

The included `author/trf23/tanimoto_gp.py`, `tanimoto_functions.py` and package initializer are unchanged from author commit `f0edc6b88471ccc9eb19c05ed3e16a6dbf7879e2`. The author's MIT notice, copyright Austin Tripp (2023), is retained verbatim in [licenses/tanimoto-random-features-MIT.txt](licenses/tanimoto-random-features-MIT.txt). The EVIDA adapter supplies native binary Morgan inputs, training-only target standardization, CPU settings, bounded fitting and separate latent/observation uncertainty. It calls the modern BoTorch SciPy fitting API; it does not edit the author model or kernel. Use of exact GP classes does not imply use of the paper's random-feature approximation.

**MoleculeACE.** Derek van Tilborg, Alisa Alenicheva, and Francesca Grisoni. *Exposing the Limitations of Molecular Machine Learning with Activity Cliffs*. Journal of Chemical Information and Modeling 62(23), 5938–5951 (2022). [DOI](https://doi.org/10.1021/acs.jcim.2c01073), [author repository](https://github.com/molML/MoleculeACE/tree/7e6de0bd2968c56589c580f2a397f01c531ede26).

The 30 benchmark CSVs are copied unchanged from commit `7e6de0bd2968c56589c580f2a397f01c531ede26`. The repository's MIT license notice, copyright Derek van Tilborg (2022), is retained verbatim in [licenses/MoleculeACE-LICENCE.txt](licenses/MoleculeACE-LICENCE.txt). Prepared input records derive from the official split and molar pEC50/pKi column. The data are reported-activity aggregates; the package does not add individual assay or species annotations absent from the benchmark.

**EVIDA component and adaptation.** `frozen-product/evida/activity_model.py` and `activity_inputs.py` are the exact native RF/input implementations used as the control. `gp_adapter.py` is the exact bounded adapter used for the GP run. Source hashes and per-task fitted parameters are in `source-map.json` and `model-pins.json`. Portable execution and result-checking scripts are identified separately.
