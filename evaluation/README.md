## 같은 조건의 연구 절차 16회 비교

A=직접 절차, B=EVIDA 절차. 같은 GPT-6 Sol/medium · competition Responses API · 도구 · 응답 상한으로 실제 질문 4개(IPF, PDE4B, Alzheimer, TTR siRNA)를 2번씩 반복해, 절차마다 8번 시작했습니다. 최종 출력의 과학 검토는 blind ID로 수행하고 이후 arm을 해제했습니다. 실제 실패를 포함한 원 시작 분모를 유지합니다. 공개 데모의 구독 모델 경로에 대한 평가로 소급하지 않습니다.

| 항목 | A 직접 절차 | B EVIDA 절차 |
|---|---:|---:|
| 원 시작 | 8 | 8 |
| 판단 게시 | 7/8 | 8/8 |
| 다음 행동 6요소 | 6/8 | 7/8 |
| 기전·후보·근거·다음 행동 4요소 연결 | 1/8 | 4/8 |
| 새 측정의 6요소와 결과별 판단 연결 | 3/8 | 3/8 |

여섯 요소는 관찰 단위, 비교 대상, 측정값, 조건·의존성, 기존 관측과 제안의 구분, 결과에 따른 판단 변화입니다. 네 요소는 질문에 필요한 기전, 후보, 근거의 적용 조건/의존성, 다음 행동이 함께 traceable한지를 봅니다. 새 측정 카드는 실제 수행 결과가 아니라 측정의 설계와 후속 판단 연결을 검토합니다. 연구자의 조건 확인이나 기존 자료 조회는 새 측정 카드와 분리합니다.

[집계 summary.json](summary.json) · [원 16행 CSV](rows.csv) · [효율·토큰 정의](efficiency.json)

원 CSV의 `blind_output_id`는 동결 출력의 연결 키입니다. `published_answer=False`도 제외하지 않습니다. `claims_supported` 등은 실제로 검토한 주장의 분모이며 전체 논문 수나 전체 후보 수와 다릅니다. `catalog_candidates`는 기전·표적·접근·구조 등 선택지 수로, 고유 물질 수와 구분합니다. 과학 worker 실패는 HTTP·원문 수신·도구 실패이며 provider 응답 실패와 구분합니다.

입력 토큰에는 `cached_input_tokens`가 포함됩니다. 캐시 값을 다시 더하지 않습니다. 호출 A 117 / B 101회, 입력 11,625,335 / 11,534,710 · 출력 114,320 / 100,126 · 캐시 4,592,200 / 6,008,740은 원 영수증 218건에서 집계해 검수한 값입니다. 가격, 크레딧 잔액, 사용자 시간 절감으로 환산하지 않습니다.

질문 4개에 대한 개발 비교이며, 모든 질환·과학적 효능·방법에서의 보편적 우위를 주장하지 않습니다. 다른 평가의 결과는 평가군을 구분해 보고하며, 이 점수를 소급해 바꾸지 않습니다.

## Claude 구독 경로의 추가 질환 평가

류마티스 관절염·파킨슨병·낭성섬유증·췌관선암의 4개 질환 × 2개 지시 방식, 원래 8개 연구 단위를 Claude 구독의 Opus 5/high에서 별도로 시작했습니다. 같은 질문의 수동 전송 수리를 포함해 실행 시도 12회, 예약 17회, 실제 전송 16회가 있었고, 최종 판단 게시 0건으로 종결했습니다. 최종 과학 정확도는 평가할 수 없습니다. 원래 8개의 분모, 미시작, 실패, 형식 수리, 입력 크기 제한을 [추가 평가 종료 기록](claude-expansion-20261002/README.md)에 보존했습니다. 위의 GPT 16회 비교와 부품 벤치마크의 결과는 각 평가군의 결과로 유지합니다.
