# Sources, licenses and adaptations

**CheMeleon.** *Descriptor-based Foundation Models for Molecular Property Prediction*. [Paper](https://doi.org/10.48550/arXiv.2506.15792), [author repository](https://github.com/JacksonBurns/chemeleon/tree/b5e5bd88a7070c3f278e7e65e85b792617bf125c), commit `b5e5bd88a7070c3f278e7e65e85b792617bf125c`. Author `chemeleon_fingerprint.py`, regression evaluation/fine-tuning reference code and the MIT license are retained unchanged under `chemeleon-trial/author/`. The official weight snapshot is [Zenodo record 15460715](https://zenodo.org/records/15460715), MIT; its 34,859,448-byte file SHA-256 is `c376624d3407204e780a0ed13a9ac097cc9bb1c13ef89cdbc633c1715c183651`. The weight file is downloaded explicitly and hash-checked, not bundled. The local frozen encoder adapts checkpoint location/device and batching; it retains the author's fingerprint call. Fine-tuning follows the author's Chemprop regression workflow with documented native scaffold split, fixed seed, matched random architecture, bounded epochs and local logging adaptations. This is not a replication of every experiment in the paper.

**MoleculeACE.** Derek van Tilborg, Alisa Alenicheva and Francesca Grisoni. *Exposing the Limitations of Molecular Machine Learning with Activity Cliffs*, JCIM 62(23), 5938–5951 (2022). [Paper](https://doi.org/10.1021/acs.jcim.2c01073), [source commit](https://github.com/molML/MoleculeACE/tree/7e6de0bd2968c56589c580f2a397f01c531ede26). Prepared input/gold files derive from the official 30 target/endpoint datasets, existing train/test assignments and p-activity labels. Original CSV identities are in `dataset-pins.json`; prepared bytes are verified against the trial protocols. The repository MIT notice is retained in `licenses/MoleculeACE-LICENCE.txt`. No source condition annotations are invented.

**Underlying ChEMBL data.** ChEMBL, maintained by EMBL-EBI and contributors, supplies the curated reported bioactivities underlying the benchmark. Its data use [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/), as stated by the [official ChEMBL licensing page](https://chembl.gitbook.io/chembl-interface-documentation/about#data-licensing), checked on 2026-10-11. The [data notice](licenses/ChEMBL-DATA-NOTICE.md) records transformations and attribution. The MoleculeACE software MIT notice does not override the underlying data terms. No unrecorded ChEMBL release version or original experimental condition is invented.

**RF/GP references and EVIDA code.** Native EVIDA RF/input code is retained under `tanimoto-trial/frozen-product/`, with original source hashes. Archived reference predictions were produced using the exact Tanimoto kernel GP from [Tripp et al., NeurIPS 2023](https://github.com/AustinT/tanimoto-random-features-neurips23/tree/f0edc6b88471ccc9eb19c05ed3e16a6dbf7879e2), with EVIDA training-only label standardization and bounded CPU fitting. The neighboring conditional activity model package documents full RF/GP refitting; this package consumes its original pinned predictions without needing the GP training library. CheMeleon author code is used under its own license; this attribution does not relicense third-party materials.

Original scientific outputs and fitting function bodies are preserved. Workstation paths and a device UUID in public provenance/logs are replaced by logical placeholders and recorded with original/public hashes. The public preparation, verification and recalculation helpers are EVIDA packaging code, not new author methods or performance evidence.

The seven files in `provenance/portable-source-check.json` are unchanged EVIDA fitting/scoring adapters and metrics, not seven author functions. The author fingerprint, regression evaluation and fine-tuning reference files retain the CheMeleon MIT license. The full source map distinguishes their original bytes from sanitized protocol/log containers. Independent review and portable recalculation code are separate EVIDA code.
