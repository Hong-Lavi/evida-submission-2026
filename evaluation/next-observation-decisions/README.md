# EVIDA next-observation decision comparison

This is a recorded development comparison of three ways to choose the next useful observation: EVIDA's current native decision response, the native response with a conditional decision aid, and a plain model response. All twelve final answers came from **gpt-6-sol, medium effort**. A separate blinded scientific review used one gpt-6-sol medium session. The review could partly infer method from answer format.

The fixed design has two authored cases, each with an initial decision and a result update. Each method answered all four case-stages once. NERA asks whether a donor-paired functional contrast supports a limited MKP1-related contribution or calls for repair of altered upstream drug function. BRAF asks whether an initial functional MAPK response occurred before a high late signal; its update presents a failed readout. The literature is background, cited by DOI in `case-cards.json`. The new scenarios, assay availability and validation, costs, predictions, and result cards are **synthetic assumptions**. No new laboratory experiment was performed.

The frozen rubric requires all five scientific dimensions to pass for primary success. Each method scored **3/4 pass and 1/4 partial**. All three partial answers occur on the BRAF failed-readout update: they route the invalid measurement to repair but do not fully condition execution on the unknown repair cost and budget. This is a tie on these cases, not a superiority or biological-validity estimate. The conditional decision aid remains useful for inspecting outcome-to-decision mappings; this finding motivates explicit repair-cost and remaining-budget handling. The archived scores refer to the frozen comparison; the twelve answers were not regenerated or rescored for this package.

`responses/` holds the twelve unchanged final answers; `judgments/` holds their frozen scientific assessments. `results.json` links answers to methods, case-stages, and scores; `model-identity.json` records the actual model from each archived CLI receipt. `schema-diagnostics.json` distinguishes two frozen request-contract rejections from the current publication schema. Q09 has six invalid anchor-path types under both contracts. Q11 lacks `outcome_links` under the stricter requested check contract, while the current legacy publication schema accepts its structure. Neither structural check is a claim of product publication, and these diagnostics are separate from scientific scores. `rubric-frozen.json` and `case-cards.json` provide the scoring rule and compact scientific inputs. The case cards preserve the authored conditional model and necessary source facts without redistributing the long article extracts.

Run `python verify_recorded_results.py` from this directory to check the staged files' SHA-256 values, the original-answer hashes, all twelve judgments, the fixed denominator, and the per-method arithmetic. This verifies archived bytes and counts; it does not rerun a model or certify the underlying biology. Repeating model generation requires its own controlled protocol and access to the private delivery record.
