# 계산 도구와 결과 확인

EVIDA에는 계산·분석 함수43종이 등록돼 있습니다. 주 오케스트레이터는 줄이려는 불확실성과 필요한 입력을 바탕으로 도구를 선택합니다.

| 확인하려는 것 | 연결한 도구·분석 |
|---|---|
| 분자 구조와 물성·노출 조건 | RDKit, ADMET-AI, Dimorphite-DL, Gypsum-DL, 노출 조건 비교 |
| 결합 부위·자세·상호작용 | fpocket, AutoDock Vina, PoseBusters, ProLIF, 기준 포즈 비교 |
| 배좌·분자 기하·시간에 따른 움직임 | xTB, CREST, OpenMM, MDAnalysis |
| 후보 생성·합성 가능 경로 | CReM 기반 구조 제안, SCScore, AiZynthFinder |
| RNA 후보·가닥·결합·전달 | ViennaRNA, RIsearch2, IntaRNA, ENsiRNA 계열, seed·전사체·영역·전달 모형 분석 |
| 경로와 다음 확인 | 조절 패턴·경로 가설·상태·강건성, 효소 속도, 관측 선택과 보고 활성값 비교 |

함수43종에는 같은 소프트웨어의 서로 다른 분석도 포함됩니다. 전체 모델 함수106종과 worker87종에는 문헌 조회·입력·기록 작업도 포함됩니다.

## 실행 결과 읽기

화면은 완료·부분 결과·실패·재사용을 구분합니다. **값·단위·실행 조건**을 펼치면 해당 산출물의 원수치를 읽고, **원결과 전체·조건 보기**에서 입력·조건·출처를 확인합니다. 새로운 입력에 과거 계산을 연결할 때는 원래 계산 조건을 함께 검토합니다.

결과가 다를 때는 각 도구의 예측 대상, 입력과 가정, 적용 범위를 비교합니다. 포즈 점수·열역학·노출·독성·경로의 관측량을 구분한 뒤, 남은 차이를 다음 실험의 질문으로 연결합니다.

## 연결과 검수 기록

등록함수 전체의 실행 산출물 연결을 확인했습니다. 보존 실행 증거와 현재 환경의 직접 실행은 구분해 기록합니다. RNA 일부 보존 실행에는 당시 adapter 전체해시가 남아 있지 않아, 저자 코드·원입력·원출력·버전 대조 범위를 함께 명시합니다. 현재 연구에서의 도구 선택과 해석은 질환별 연구 기록에서 확인합니다.

외부 도구는 저자 라이선스와 자원 조건을 따릅니다. `configs/`의 자원 템플릿과 고정 환경 목록을 준비하고 도구별 입력·출력 검수를 거쳐 실행합니다.
