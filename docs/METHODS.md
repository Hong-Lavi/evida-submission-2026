# 현재 사용 방법과 완료한 시험

현재 운영 구성과 개발 중 완료한 비교를 구분해 정리했습니다. 각 도구의 출력은 원 출처·조건·계산 범위와 함께 연구 기록에 남깁니다.

## 현재 제품 구성

| 구성 | 역할과 확인 범위 |
|---|---|
| LLM 연구 조정 + Store/Runner | 질환 목표부터 다음 행동까지 진행하며 출처와 실행 결과를 연결함. 현재 공개 연결은 Claude Opus 5/high임 |
| 공개 문헌·표적·화합물 조회 | 원 결과, 출처·원행과 적용 조건을 보존함 |
| RDKit 구조 검토·2D 표시 | 저장된 SMILES와 정확한 후보 ID로 실제 출발·생성 구조를 표시함 |
| 기전 비교와 후보 연결 | 질환 적합성·근거 수준을 함께 보여주고, 연결된 후보와 다음 확인을 같은 화면에서 검토함 |
| CReM·규칙 기반 유사체 생성 | 공개 출발 화합물에서 후속 구조를 생성하고 실제 출발 구조와 변경 관계를 보존함 |
| 활성 입력 정비와 Random Forest | 표적·측정 종말점·관계·단위를 구분함. 모델의 실제 평가와 적용 조건을 만족할 때 예측을 사용함 |
| MedCPT 의미 검색 | 저장 문헌의 제목·초록을 선택적으로 검색하며 새 자료의 증분 색인을 지원함. 원문과 서지 정보를 함께 보존함 |
| RNA 관련 계산 | 전사체·서열 조건에 따라 RNA 접근성, 상보 결합과 후보 검토 도구를 사용함 |

생성 구조는 다음 기능 측정의 출발점으로 다룹니다. 원 화합물의 실측값, 생성 후보의 계산값과 연구자가 제공한 관측을 각각 표시합니다.

## 완료한 개발 비교

| 비교 | 범위와 현재 반영 |
|---|---|
| 두 연구 절차 | 같은 모델·도구·응답 예산의16시작. 평가 정의와 모든 시작의 결과를 `evaluation/`에 수록함 |
| MedCPT 검색 | SciFact의 근거가 있는188질문에서 BM25와 비교함. 해당 검색 부품과 저장 문헌의 실제 조회를 검수함 |
| 활성 입력 보수 | 동일 평가 화합물의 정확 IC50 평가값을 기준으로 학습 입력 정비 전후를 비교함 |
| 기전·후보 선택법, REINVENT4 DAP, source-local CReM | 실제 로컬 시험의 출력·조건을 보존함. 이번 운영 구성은 위 ‘현재 제품 구성’을 기준으로 동결함 |
| Biomni·Virtual Lab·CellBench 및 검색 결합 | 저자 방법과 공개 구현을 검토·시험한 기록을 보존함. 현재 제품에 적용한 구성과 전체 저자 시스템의 재현을 구분함 |

ALS 사례는 공개 실험 결과와 검토 피드백을 연구 기록2→14에 반영한 예입니다. 기록15는 FAAH 후속 실험 카드의 작업 유형과 요청 형식을 보완한 기록입니다. 근거가 적용되는 유도결핍 조건과 산발성 환자 유래 세포에서 확인할 조건을 나누어 다음 비교를 제시합니다.

질환·시험 조건·생성기별 출발 집합과 분모는 비교에서 함께 확인합니다. 개별 계산 결과의 해석과 후보의 실측 효능 검증은 다음 실험 카드에 연결합니다.

[검색·활성 입력 비교의 평가 조건과 원 집계](../evaluation/METHODS_EVALUATION.md)
