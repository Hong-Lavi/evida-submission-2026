# 제품 구성과 비교 근거

EVIDA는 연구 목표, 조사와 계산, 가설과 다음 실험, 결과 반영을 하나의 연구 기록으로 연결합니다. 오케스트레이터는 현재 근거와 남은 질문을 읽고 다음 작업을 선택하며, 실행 결과를 다시 판단에 사용합니다.

## 연구를 진행하는 구성

| 구성 | 역할 | 연구자가 확인할 기록 |
|---|---|---|
| 목표 구조화 | 질환·원하는 변화·대상·제약을 연구 질문으로 정리 | 원요청, 구조화한 조건, 수정 이력 |
| 공통 추론 코어 | 문헌에서 추출한 조건부 원리를 조사·계산 선택과 가설·실험·재판단에 활용 | 사용한 원리, 적용 조건, 원문 위치 |
| 주 오케스트레이터와 Store/Runner | 작업의 이유를 정하고 도구를 실행하며 결과와 실패를 보존 | 조사 계획, 진행 상황, 실제 실행 기록, 게시된 판단 |
| 문헌·웹·API 접근 | 현재 질문에 필요한 공개 문헌과 임상·표적·약물 자료를 회수 | 출처, 읽은 범위, 원행, 회수 상태 |
| 계산·분석 도구 | 분자 물성·활성·구조·동역학·역합성·RNA 등 질문에 맞는 계산 수행 | 입력, 도구·버전, 원값·단위, 적용 조건 |
| 가설과 실험 설계 | 경쟁 설명의 예측을 비교하고 다음 확인을 제안 | 비교군, 바꿀 변수, 고정 조건, 판독값, 결과별 다음 행동 |
| 관측과 재판단 | 새 결과를 대상·조건·출처와 연결하여 앞선 판단을 검토 | 관측 원문, 이전 판단, 유지·수정 이유와 후속 확인 |

코어 구축에는 원래 500개 문헌 사례를 사용했습니다. 현재 근거 493개, 철회 이력을 둔 역사 사례 1개, 범위 밖 6개의 처분을 보존하고 48개 조건부 원리로 연결했습니다. 사례의 관찰→가설→비교→결과→다음 판단과 원문 위치를 함께 읽을 수 있습니다. 자세한 추출·통합·검수 과정은 [추론 코어](REASONING_CORE.md)에 있습니다.

제품에는 43종 계산·분석 함수가 연결돼 있습니다. 무엇을 계산할지는 현재 연구 질문과 필요한 입력에 따라 정합니다. 서로 다른 도구의 결과를 비교할 때에는 측정하는 성질, 가정과 조건을 함께 확인합니다. 도구 목록과 입력·실행 근거는 [계산 도구](COMPUTATION_TOOLS.md)에 정리했습니다.

## 비교 결과를 읽는 방법

각 실험은 비교 대상, 동결된 코드·모델, 입력 자료, 실행 예산과 평가 기준을 함께 기록합니다. 독립 연구 사례 수와 같은 사례의 반복·단계 수를 구분하고, 모든 시작의 완료·실패·미채점 상태를 보존합니다.

| 비교 | 시험 자료와 분모 | 결과 자료 |
|---|---|---|
| 같은 LLM·코어 유무·PaperQA Docs 워크플로의 문헌 답변 | 원문 제공15문항·검색20문항, 총120방식·문항 조합 | [정답·완료·전체 분모](../evaluation/literature-reasoning/README.md) |
| 목표·교정, 계산 기록, 도구 실행·복구, 임상 판단 | 독립 사례 8·4·4·3개, 원조건 100단계와 임상 24단계 | [모든 기준·채점 상태·비교 그래프](../evaluation/module-comparisons/README.md) |
| 직접 절차와 EVIDA 연구 절차 | 연구 질문 4개 × 절차 2개 × 반복 2회, 총 16번 시작 | [평가 정의·원 행·집계](../evaluation/README.md) |
| BM25와 MedCPT 검색 | NFCorpus 문헌 3,633개·질의 323개 | [공개 검색·활성 평가](../evaluation/components-20261002/README.md) |
| 훈련 평균과 제품 RF 활성 예측 | MoleculeACE 30과제·평가 기록 9,802건 | [분할·예측·재계산](../evaluation/components-20261002/README.md) |
| 출발 화합물에서 후속 구조 생성 | CReM 10과제의 실행 상태, 완료 5과제의 반환 구조 300건 | [구조·출처·재계산](../evaluation/crem-generation-20261002/README.md) |
| 검색·활성 입력의 구성 비교 | 비교별 고정 질문·화합물·측정 조건 | [방법별 평가 기록](../evaluation/METHODS_EVALUATION.md) |

연구 흐름 비교는 판단과 다음 행동의 연결을, 검색 비교는 관련 문헌의 순위를, 활성 비교는 공개 측정값에 대한 예측 오차를 평가합니다. 새 후보의 실제 효과를 확인할 실험은 각 연구의 다음 확인에 연결합니다. 모델·입력·방법이 다른 실행은 각각의 분모와 원 기록에서 살펴봅니다.

## 실행 경로와 사용자 선택

공개 기본 경로는 대회 API의 GPT-6 Sol · medium입니다. 대회 API가 사용량 한도(HTTP 403)를 반환하면 방문자가 제출자 개인 구독의 Claude Opus 5 · medium 또는 GPT-6 Sol · medium을 직접 선택하여 재실행할 수 있습니다. 화면은 선택한 경로와 실제 응답 모델, 해당 경로의 이용 상태를 표시합니다.
