# EVIDA 실행 방법

**[EVIDA 열기](https://evida.ndagentevida.com)**

EVIDA는 질환과 연구 목표를 기전·후보·근거·다음 실험으로 연결합니다. 저장된 연구를 읽거나 새 질문과 관측을 입력해 연구를 이어갑니다.

질환과 목표를 받은 오케스트레이터가 조사할 기전·후보와 도구를 선택합니다. 각 연구에서 원요청과 실제 실행, 게시된 판단을 차례로 읽을 수 있습니다.

1. **한눈에 보기·목표**에서 연구 질문과 현재 판단을 읽습니다.
2. **기전**에서 질환과 기전의 연결, 비교한 설명을 확인합니다.
3. **후보**에서 구조·출처·검토 상태를 엽니다. 실제 계산 링크를 누르면 계산 입력과 원값·단위를 확인할 수 있습니다.
4. **실험**에서 대상·비교군·판독값·조건·결과별 다음 행동을 읽습니다.
5. **결과 반영**에서 추가된 관측과 판단의 변화를 확인합니다. 시연용 가상관측은 해당 표시와 함께 읽습니다.
6. **근거·원자료**에서 문헌과 원행을 대조합니다. 닫으면 앞서 보던 후보나 실험으로 돌아옵니다.

진행 중인 연구에는 현재 조사 계획, 실행 상태와 확보한 자료가 표시됩니다. 게시한 부분 판단과 원목표의 남은 연결을 구분하고, 결과별 다음 행동을 확인합니다. 저장 결과를 읽는 동안 모델 호출은 발생하지 않습니다.

## 새 연구 시작하기

**연구 목록 → ＋ 새 연구**에서 연구할 질환·현상과 바꾸고 싶은 결과를 입력합니다. **함께 비교 · 저분자부터 · siRNA부터** 중 우선 접근을 고르고 **목표에서 연구 시작**을 누릅니다.

```text
뇌전증의 기전과 치료 표적, 저분자 후보를 찾고 싶습니다.
근거와 실제 계산을 검토하고 다음에 어떤 실험으로 방향을 결정할지 제안해주세요.
```

이미 확보한 표적·후보·실험 조건이 있으면 함께 적습니다. 보유한 저분자 CSV(ID·SMILES)나 RNA 실험 TSV도 화면의 양식에 맞춰 첨부할 수 있습니다. 자료의 출처와 측정 조건을 함께 전달해주세요.

기본 모델은 **대회 API의 GPT-6 Sol · medium**입니다. 화면 위의 **모델 이용 안내**에서 경로별 이용 상태를 확인합니다. 대회 API가 토큰 사용량 한도(HTTP 403)를 반환하면 **제출자 개인 구독 모델(Claude Opus 5 · medium 또는 GPT-6 Sol · medium)**을 직접 고르고 주의 사항을 확인한 뒤 재실행할 수 있습니다. 선택한 경로와 실제 응답 모델이 기록됩니다.

## 결과를 반영하고 다음 연구로 이어가기

- **설명 물어보기:** 저장된 판단의 이유를 질문합니다. 예: “이 실험에서 비교할 대상과 핵심 판독값을 세 문장으로 설명해주세요.”
- **질문·조건·관측 추가:** 새 결과의 출처·대상·조건과 측정값을 전달합니다. 초안을 확인해 보내면 이전 판단과 후속 판단을 함께 보존합니다.
- **다른 기전:** 기전 상세의 **이 기전 검토하기**에서 이유를 적고 **선택만 저장** 또는 **이 경로로 검토 시작**을 고릅니다. 후자는 실제 검토를 실행합니다.

작업 중 조건이 바뀌면 앞선 실행을 이전 조건의 기록으로 남기고, 확보한 원문과 계산을 후속 검토에 재사용합니다. 새 연구와 후속 검토의 소요 시간은 필요한 조사와 계산, 외부 자료원의 응답에 따라 달라집니다.
