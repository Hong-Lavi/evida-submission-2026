# EVIDA 실행 방법

**[EVIDA 열기](https://evida.ndagentevida.com)**

EVIDA는 질환과 연구 목표를 기전·후보·근거·다음 실험으로 연결합니다. 보존된 연구는 바로 읽을 수 있고, 새 질문과 관측을 입력해 후속 연구를 시작할 수 있습니다.

## 1. 저장된 실제 연구 살펴보기

| 연구 | 확인할 흐름 |
|---|---|
| [IPF 연구 기록4](https://evida.ndagentevida.com/?workspace=ws_3c8fe9df9cd14339) | LPAR1·PDE4B 등 검토 기전 → 생성후보 기록12건 → 연결 후보·출발 화합물 → 다음 실험 |
| [PDE4B 연구 기록8](https://evida.ndagentevida.com/?workspace=ws_1ff05aa2d7c24e0e) | 누적 생성후보 기록48건·최신 집합12개 → proposed-2와BDBM14364의 구조 → PDE4B2/PDE4D2 기능 비교 설계 |
| [ALS 연구](https://evida.ndagentevida.com/?workspace=ws_4475545a286541b2) | 기록2→14의 공개 결과·검토 피드백 반영 → 조건별 판단과 후속 실험. 기록15는 FAAH 실험 카드의 작업 유형·요청 형식 보완 |

1. **한눈에 보기**에서 현재 판단·우선 후보·다음 실험을 읽습니다.
2. **기전**에서 질환과 기전의 연결, 연결된 후보를 확인합니다.
3. **후보**에서 2D 구조·실제 출발 화합물·생성 경로를 엽니다.
4. **실험**에서 대상·비교군·판독값·조건·결과별 판단을 읽습니다.
5. **근거·원자료**를 열어 실제 문헌·행·측정 조건을 대조합니다. 닫으면 앞서 보던 후보나 실험으로 돌아옵니다.

생성 구조의 기능은 후속 비교 실험에서 확인할 대상으로 표시합니다. 저장 결과를 살펴보는 동안 모델 호출은 발생하지 않습니다.

## 2. 새 질환이나 표적에서 시작하기

메뉴의 **새 연구**를 열고 **연구할 질환·현상과 바꾸고 싶은 결과**를 입력합니다. **함께 비교 · 저분자부터 · siRNA부터** 중 우선 접근을 고른 뒤 **목표에서 연구 시작**을 누릅니다.

현재 모델은 **Claude Opus 5 · high**입니다. 화면 위 모델 이름 또는 입력 아래 **모델 이용 안내**에서 실제 가용 상태를 확인합니다. Claude는 개발자 구독으로 제공하며, 대회 API는 할당량 소진 상태입니다. 심사와 지속 사용에는 대회 API 크레딧 확보 후 연결을 권장합니다.

**질환에서 출발하는 예시**

```text
알츠하이머병의 진행을 늦출 치료 연구 방향을 찾고 싶습니다.
현재 확보한 표적이나 후보는 없습니다. 사람 연구와 질환 관련 세포·동물 연구를
읽어 경쟁 기전을 비교하고, 유용한 방향의 실제 후보와 구조를 찾아 주세요.
다음에 어떤 비교 실험을 하면 방향을 결정할 수 있을지도 제안해 주세요.
```

**정해진 표적에서 출발하는 예시**

```text
PDE4B를 겨냥하는 저분자를 연구하고 싶습니다. 보고된 화합물과 원 실험 조건을
확인하고 그 화합물에서 새 구조를 제안해 주세요. 출발 화합물과 제안 구조의 물성,
활성 예측의 적용 범위, PDE4D와의 선택성을 확인할 기능시험을 함께 검토해 주세요.
```

**siRNA 방향의 예시**

```text
간에서 인간 TTR 발현을 낮출 siRNA를 검토하고 싶습니다.
공개 전사체와 후보 구간을 먼저 확인해 적절한 구간을 제안하고,
후보 서열의 접근성·비표적 가능성과 다음 세포 실험을 비교해 주세요.
```

새 연구는 실제 모델·자료 조회·도구를 실행하며 질문과 외부 자료원의 응답에 따라 시간이 달라집니다. 진행 영역에서 현재 작업과 확보한 자료를 확인할 수 있습니다.

## 3. 설명·새 관측·다른 기전으로 이어가기

- **설명 물어보기:** 저장된 판단의 이유를 묻습니다. 예: “다음 실험에서 어떤 두 물질을 비교하고 무엇을 읽어야 하는지 세 문장으로 설명해 주세요.”
- **질문·조건·관측 추가:** 목표·조건 정정이나 실제 관측의 출처·조건을 전달합니다. 초안을 확인한 뒤 명시적으로 보냅니다.
- **다른 기전:** `기전` 탭에서 항목을 누르고 **이 기전 검토하기**를 엽니다. 이유를 적은 뒤 **선택만 저장** 또는 **이 경로로 검토 시작**을 고릅니다. 후자는 실제 새 검토를 시작합니다.
- 진행 중인 작업이 있는 경우 새 선택·조건을 저장하면 기존 작업을 이전 조건의 기록으로 보존합니다. 확보된 원문·계산을 후속 검토에 재사용합니다.

## 4. 보유 자료에서 시작하기

새 연구에서 저분자 후보 CSV(ID·SMILES) 또는 RNA 실험 TSV를 첨부할 수 있습니다. 화면의 양식과 입력 설명을 확인하고 자료의 출처·측정 조건을 함께 입력합니다.

[읽기 전용 미리보기](https://evida.ndagentevida.com/preview/)에서는 보존 연구와 화면을 확인합니다. 실제 새 요청은 본 주소에서 시작합니다. 현재 공개 서비스는 방문자가 같은 운영 연결과 호출 한도를 공유합니다.
