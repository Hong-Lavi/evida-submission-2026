# 문헌에서 만든 추론 원리

추론 코어는 실제 연구의 **관찰 → 가설 → 비교 → 결과 → 다음 결정**을 추출하고, 그 사례들이 지지하는 조건 안에서 일반화한 48개 원리를 사용합니다.

## 구축 과정

원래 분모는 500개 사례입니다. 기전·생물학 180개, 임상·개발 180개, 계산·실험 플랫폼 140개를 분석 대상으로 삼았습니다. 각 사례에서 원문과 확보한 보충자료의 위치를 연결하고 연구자가 무엇을 비교했고 무엇을 확인한 뒤 다음 결정을 내렸는지 정리했습니다.

현재 근거로 다룬 493개, 철회 이력을 함께 둔 역사 사례 1개, 범위 밖으로 분류한 6개의 처분을 모두 남겼습니다. 494개 논증 기록을 바탕으로 임상 11개·기전 19개·플랫폼 18개의 조건부 원리로 통합했습니다. 같은 내용을 반복하는 사례도 별도의 독립 원리로 부풀리지 않고 연결 관계와 이유를 남겼습니다.

원리별로 적용 조건, 생성 관점, 선택할 정보, 대안을 구별하는 비교, 결과별 갱신과 실제 사례를 구성했습니다. 독립 검수자는 원리의 핵심 주장과 연결 원문 위치를 대조해 적용 범위와 해석을 정정했습니다. 전체 사례의 처분·연결은 전수 확인했고, 독립 원문 대조는 기록에 명시한 주장·위치를 대상으로 했습니다.

## 제품에서 확인할 자료

- `evida/reasoning_corpus_coverage.json`: 원500개 사례의 처분, 논증과 원리 연결.
- `evida/reasoning_perspectives.json`: 검색·활용할48개 조건부 원리.
- `evida/reasoning_principle_details.json`: 적용 조건·실제 사례·원문 위치와 검수 기록.
- 화면의 원리 상세: 적용 관점 → 해당 사례 → 읽은 범위와 원출처 식별 기록.

원리와 모델이 만든 새 제안은 현재 연구의 실제 근거·계산과 연결해 검토합니다. 평가는 각 벤치마크의 입력과 분모, 동일 모델의 비교 조건을 함께 기록합니다. 참고한 사례와 평가 문헌의 겹침도 평가 조건에 표시합니다.
